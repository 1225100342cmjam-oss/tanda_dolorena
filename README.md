# Tanda Doloreña (TDD)

## Puesta en marcha
1. Copia esta carpeta y, dentro de ella, genera las carpetas de plataforma:
   flutter create .
   (No sobrescribe lib/, test/ ni pubspec.yaml con tu código; si te pregunta, conserva los archivos de este proyecto.)
2. Borra test/widget_test.dart si `flutter create` lo generó (apunta a MyApp, que no existe aquí).
3. flutter pub get
4. flutter test   -> 12 pruebas en verde
5. flutter run
